How the Ask Widget Works

Highlight a sentence below, right-click, and choose ELI5, Prove it, or Ask a question.

This page exists to exercise the widget. Some statements below are deliberately true and some are deliberately false, so that "Prove it" — which greps the project's real source — has something to confirm and something to contradict.

Networking

The Ask Widget server binds to 0.0.0.0 on port 8899, listening on all network interfaces so other machines on the LAN can reach it.

The sentence in the box above is the headline fact-check target. Highlight it and choose Prove it — the answer should come back Not supported and cite the real default host in __main__.py.

Python packaging

Homebrew's Python is a PEP 668 externally-managed environment, so a bare pip install is refused and you must create a virtual environment first. Highlight that phrase and choose ELI5 for a plain-language explanation.

Security

Every request to /ask must carry a per-server random token that is baked into the served ask.js, and the server additionally checks the Origin and Host headers to defeat DNS-rebinding. Highlight this and choose Ask a question to dig into why a token alone is not enough.
