# Onyx 0.6.2

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

Download `Onyx-0.6.2-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## New app icon

The gem now sits on a dark square. On macOS 26 Tahoe, which draws every app icon as a rounded square, the old gem-only icon showed inside a grey square macOS added. The new icon is a Liquid Glass icon that follows Tahoe's dark, tinted and clear modes. Earlier macOS versions show the same icon, flat.

If the Dock still shows the old icon after updating, run `killall Dock`.

First time on this Mac? On first launch Onyx opens **Settings ▸ Setup**, a checklist for the CLI sign-in, your Obsidian vault, the Artifacts folder and the Obsidian plugin. See the [README](https://github.com/cxrobx/onyx#readme).
