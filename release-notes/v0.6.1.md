# Onyx 0.6.1

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

Download `Onyx-0.6.1-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## Setup on a new Mac

On first launch Onyx opens **Settings ▸ Setup**, a checklist with a fix beside each step:

1. **Claude or Codex, signed in.** Run `claude` once and sign in with a paid claude.ai plan, or sign the Codex CLI in with ChatGPT.
2. **Obsidian vault.** Onyx picks the vault Obsidian has open.
3. **Artifacts folder.** Onyx creates `~/Documents/Artifacts` for you.
4. **Onyx plugin in Obsidian.** Press **Install plugin**, then quit and reopen Obsidian. If Obsidian shows Restricted mode, turn it off in Settings ▸ Community plugins.
5. **Vault look.** Arrives from the plugin within a few seconds.

## Fixed

- On a Mac other than the one Onyx was built on, the vault look never arrived and the Artifacts folder didn't exist. Onyx now finds your Obsidian vault, creates the Artifacts folder, and carries the Obsidian plugin inside the app.
- Diagnostics showed nothing when a CLI wasn't signed in, the one case they're for. They now show the repair step.
