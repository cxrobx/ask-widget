# Onyx 0.6.0

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

Download `Onyx-0.6.0-macOS-arm64.dmg`, open it, and drag Onyx to Applications. A ZIP is available as an alternative. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

This release includes a tabbed reader, saved page highlights and notes, questions about a whole page without selecting text, and a related-content map. It also improves tab navigation and trackpad back/forward swipes.

The DMG contains the Onyx app. The Alfred and Obsidian integrations are separate installs; the Obsidian plugin is built from source. See the [README](https://github.com/cxrobx/onyx#readme) for setup and usage.
