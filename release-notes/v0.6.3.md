# Onyx 0.6.3

**Before you download:** Onyx needs either the Claude Code CLI signed in to a paid claude.ai plan, or the Codex CLI signed in with ChatGPT. Onyx does not use API keys or metered API billing. This release runs on Apple Silicon (arm64) Macs with macOS 13 or newer.

Download `Onyx-0.6.3-macOS-arm64.dmg`, open it, and drag Onyx to Applications. The app is signed with a Developer ID certificate and notarized by Apple. To verify a download, place its matching `.sha256` file beside it and run `shasum -a 256 -c <filename>.sha256`.

## The gem stands alone again

On first launch Onyx gives itself the transparent gem as a custom icon, the same thing Finder's Get Info does when you paste an icon. That works on every macOS, including macOS 26 Tahoe, where an app's own icon is always drawn as a rounded square. Until then, or where Onyx can't write to its own app (a shared Applications folder, or running it straight from the disk image), you see the shipped icon: the gem on a dark square.

Like any custom app icon, it changes the app bundle after Apple's signature check, so `codesign --verify` reports it. Onyx keeps running normally.

To keep the dark-square icon instead:

```bash
defaults write com.cx.onyx customIcon -bool false
```

Onyx removes its custom icon on the next launch. If the Dock still shows an old icon, run `killall Dock`.
